# STT Dataset

This is the clean STT dataset for the Veltech.AI model-training exercise.

## Training data

`train.jsonl` contains speech recordings and the correct human transcripts used for fine-tuning.

## Test data

`test.jsonl` is held out from training and is used for before/after evaluation.

## Audio format

Use real 16 kHz mono WAV recordings.

## Test coverage

- Tamil sentence and name
- English numbers and date
- Alphanumeric text

## Evaluation reports

- `reports/stt_before.json`: base-model evaluation result. It is currently a clean template and must be generated by the evaluation script.
- `reports/stt_after_v1.json`: v1 evaluation result. It is currently a clean template and must be generated after fine-tuning.

Do not manually invent model predictions or WER values. Generate them from the evaluation script.
